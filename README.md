## 📌 Sobre o Projeto
Projeto prático desenvolvido para consolidar e demonstrar as 4 formas fundamentais de **Data Binding** no ecossistema Angular:

1. 🔹 **Interpolation (`{{ valor }}`):** Passagem de dados da classe (componente TypeScript) para a view (HTML).
2. 🔹 **Property Binding (`[propriedade]="valor"`):** Associação de propriedades HTML e atributos dinâmicos.
3. 🔹 **Event Binding (`(evento)="metodo()"`):** Captura de eventos do usuário (cliques, inputs, submits) para a lógica do componente.
4. 🔹 **Two-Way Data Binding (`[(ngModel)]="dado"`):** Sincronização bidirecional em tempo real entre formulário e estado.
